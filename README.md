# Housing

Grosswohnsiedlungen.de is a database for large housing estates in Germany, currently work-in-progress.

It is based on the following technologies:

- Next.js
- React
- TypeScript
- Tailwind
- Prisma & PostgreSQL

## Recherche & Review

Manuell gestartete Recherche für eine bis fünf Siedlungen mit Quellenbelegen, Adminreview und protokollierter Übernahme. Einrichtung, Workerbetrieb und Tests: [docs/research.md](docs/research.md).
