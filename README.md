# Housing

Grosswohnsiedlungen.de is a database for large housing estates in Germany, currently work-in-progress.

It is based on the following technologies:

- Next.js
- React
- TypeScript
- Tailwind CSS 4 (theme and plugins configured in `src/styles/globals.css`)
- Prisma & PostgreSQL

## Configuration

See [.env.example](.env.example) for the complete configuration and
[docs/environment.md](docs/environment.md) for secret handling and browser tokens.
